# Personal Website

Minimal personal site for projects, experience, and writing.

## Stack

- Next.js 16 + React 19
- TypeScript
- CSS
- MDX
- Vercel Analytics

## Content

- Projects: `content/projects`
- Posts: `content/blogs`

## Local Development

```bash
npm install
npm run dev
```

Lint:

```bash
npm run lint
```
